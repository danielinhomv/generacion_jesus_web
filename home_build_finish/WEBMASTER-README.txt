Files and resolution
photos/png contains enlarged masters. Wide backgrounds are 3840 pixels wide; destination cards are 2400 pixels wide. Heights and native generated sizes appear in asset-dimensions.csv.
photos/webp contains matching compressed files plus 960 and 1920 pixel responsive exports. Use WebP for the website, with PNG masters available for further editing.
photos/originals retains the native image generator output, approximately 1672 to 2172 pixels wide. The larger exports are resampled, not native 4K detail. Pixel dimensions, not print DPI, determine website sharpness. Avoid enlarging beyond the supplied master dimensions.

Fidelity
These are AI reconstructions of the supplied homepage photographs, with page text and buttons removed. They closely follow the source but are not pixel-identical enlargements. Faces, architecture and fine details can vary. The original homepage is included for comparison. Recovering exact original high resolution photography requires the separate original image files.
The map is a decorative SVG trace of the homepage silhouette with rebuilt labels, not a geographic dataset. AFRICA remains a continental marker as shown. It should not be treated as an independently verified list of active countries.
The original logo embedded in the branding document is supplied unchanged as official-logo-original.png (254 x 254 pixels). The stacked SVG is a color trace of that raster, not an original vector master. Horizontal SVG variants combine the traced globe with editable text. Load Montserrat to render the wordmarks correctly. They are adaptations of the supplied branding, not newly approved original logo artwork.
Icons are recreated scalable SVG line drawings, with small differences from the reference. To use white statistics or footer icons, set the SVG color property to white. Files have transparent backgrounds.

Brand guide
Royal blue #0D47A1; sky blue #1E88E5; deep navy #0A1E3D; white #FFFFFF; action red #E53935; charcoal #2B2D31; medium gray #7A7D85; light gray #F0F2F5.
Headings Montserrat Bold; subheads Montserrat SemiBold; body Inter Regular. The supplied brand guide is included. Font binaries are not included. Keep Give buttons red; use white with blue lettering for Get Involved per project direction.

Construction
Build all headings, copy, figures, buttons and navigation as live HTML. Keep statistics separate from photographs. Use CSS gradients to reproduce the dark overlays in the reference. Use background-size:cover with responsive focal positioning; preserve faces when cropping. Hero group requires a dark left gradient for readable text. Portrait strip requires a dark right gradient. Pale white overlay can soften the village sky behind copy. The supplied screenshot is a visual reference, not the approved current website copy. Contact details and testimony text shown in that screenshot are not validated by this asset package.

Generation
Photos were reconstructed using the built-in image generation tool. No redesign was requested. The exact prompts are in reconstruction-prompts.txt.
